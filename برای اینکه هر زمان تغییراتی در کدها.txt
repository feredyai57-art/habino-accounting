برای اینکه هر زمان تغییراتی در کدهای پروژه ایجاد کردید، نسخه جدید را روی گیت‌هاب آپدیت 
(Send/Push) کنید،
 باید یک روند سه مرحله‌ایِ ساده را همیشه انجام دهید:

دستورات آپدیت نسخه در گیت‌هاب:
۱. اضافه کردن تغییرات جدید:



git add .


۲. ثبت تغییرات با یک پیام توضیحی (Commit):

git commit -m "Update project version and changes"

(شما می‌توانید به جای عبارت داخل دابل کووتیشن، توضیحات دلخواه خودتان را درباره تغییراتی که دادید بنویسید، مثلاً: git commit -m "fix accounting bug")


۳. ارسال نهایی به گیت‌هاب (Push):

git push
